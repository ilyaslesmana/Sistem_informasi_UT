### Draf `README.md` untuk Tiap Folder Tugas (`[Nama tugas X]/README.md`)

Karena sekarang ada `Code/` dan `docs/` di dalam setiap tugas[cite: 3], bagian di dalam folder tugas sebaiknya juga memetakan keduanya:

````markdown
# `[Nama Tugas X]` — [Judul Tugas]

> [Penjelasan singkat tujuan tugas, kasus yang diselesaikan, atau fitur utama yang dibangun.]

## Struktur Modul

```text
[Nama tugas X]/
├── Code/     # [Kode program / skrip / struktur proyek]
├── docs/     # [Diagram, pratinjau visual, dan dokumen pendukung]
└── README.md
```
````
