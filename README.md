## Ringkasan Repositori

Setiap folder tugas pada mata kuliah ini dipisahkan ke dalam dua jalur utama: **`Code/`** untuk implementasi kode/skrip/program dan **`docs/`** untuk dokumentasi visual, diagram, maupun berkas pendukung, lengkap dengan **`README.md`** di tiap folder tugas.

## Struktur Direktori

```text
src/
└── [Nama mata kuliah]/
    ├── [Nama tugas 1]/
    │   ├── Code/
    │   ├── docs/
    │   └── README.md
    ├── [Nama tugas 2]/
    │   ├── Code/
    │   ├── docs/
    │   └── README.md
    ├── [Nama tugas 3]/
    │   ├── Code/
    │   ├── docs/
    │   └── README.md
    └── README.md
```
